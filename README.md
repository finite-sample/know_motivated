## Motivated Responding in Studies of Factual Learning

Kabir Khanna and Gaurav Sood. 2018. *Political Behavior* 40(1): 79–101. [doi:10.1007/s11109-017-9395-7](https://doi.org/10.1007/s11109-017-9395-7)

### Replication materials

The data and R scripts are archived on [Harvard Dataverse](https://doi.org/10.7910/DVN/4JXJWI). The archive includes:

* `Study1.tab`, `Study2.tab`, `Study3.tab`: data from the three experiments, with a variable codebook (`codebook.txt`)
* R scripts for Figures 2–5 and SI Figures 1–8
* `table_and_misc_numbers.R` for the results in the main text and supplementary information, with helpers in `functions.R`
* `Khanna_Sood_PB_Replication_Readme.txt`
