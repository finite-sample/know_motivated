Replicating "Motivated Responding in Studies of Factual Learning" (Khanna & Sood, 2017)

SUMMARY:
This folder contains data and scripts needed to replicate the results in "Motivated Responding in Studies of Factual Learning", by Kabir Khanna and Gaurav Sood, to be published in Political Behavior (doi:10.1007/s11109-016-9348-6). For more information, please contact Kabir Khanna (kkhanna@princeton.edu).

REPLICATION FILES:

Data:
* Study1.Rdata --- data from Study 1
* Study2.Rdata --- data from Study 2
* Study3.Rdata --- data from Study 3

Codebook:
* codebook.txt

Scripts:
* functions.R --- General functions utilized by other scripts
* tables_and_misc_numbers.R --- Code for reproducing tables and miscellaneous numbers in the main text and supplementary information (SI).
* fig2.R --- Code for reproducing figure 2 in the main text.                   
* fig3.R --- Code for reproducing figure 3 in the main text.
* fig4.R --- Code for reproducing figure 4 in the main text.
* fig5.R --- Code for reproducing figure 5 in the main text.
* fig.si1.R --- Code for reproducing figure 1 in the SI.
* fig.si2.R --- Code for reproducing figure 2 in the SI.
* fig.si3.R --- Code for reproducing figure 3 in the SI.
* fig.si4.R --- Code for reproducing figure 4 in the SI.
* fig.si5.R --- Code for reproducing figure 5 in the SI.
* fig.si6.R --- Code for reproducing figure 6 in the SI.
* fig.si7.R --- Code for reproducing figure 7 in the SI.
* fig.si8.R --- Code for reproducing figure 8 in the SI.
